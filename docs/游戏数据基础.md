## 2. 属性

### 2.1 定义

战斗内所有实体单位都拥有属性，计算过程的典型状态：

- **原始属性**：数据文件直接定义的基本数值；信赖、潜能、模组提供的数值通常也在此步计入（得到「原始属性+」）。
- **基础属性**：原始属性经**符文运算**、取上下限后得到的数值。
- **（实际）属性**：基础属性经**属性计算器**完整处理后得到的数值，绝大多数机制以此为准。
- **属性上限/下限**：由属性类型定义，个体的上下限可被部分机制更改。

### 2.2 修饰器

修饰器（`AttributeModifier`）在获得原始属性后、决定最终数值前收集，分四种：

| 类型 | 含义 |
|---|---|
| 直接加算 `ADDITION` | 对基础数值加算 |
| 直接乘算 `MULTIPLIER` | 对「直接加算」后的结果乘算 |
| 最终加算 `FINAL_ADDITION` | 对「直接加算 + 直接乘算」后的结果加算（鼓舞） |
| 最终乘算 `FINAL_SCALER` | 对其余三种计算方式完成后的结果乘算 |

### 2.3 符文运算

符文（rune）在「入场前」修改干员/敌人属性。加算优先级高于乘算：

- 符文加算结果：`Rp = p1 + p2 + … + pn`
- 符文乘算结果：`Rt = t1 × t2 × … × tn`
- 基础值：`A = Rt × (α + Rp)`（`α` 为符文运算使用的输入值）

**藏品符文**（集成战略等）：乘算为**倍率相加**而非叠乘：

- `Cp = cp1 + cp2 + … + cpn`
- `Ct = ct1 + ct2 + … + ctn`
- 叠加后：`A+ = Ct × (A + Cp)`，`A+` 替代 `A` 继续参与属性基本公式。

### 2.4 属性基本公式

- 直接加算结果：`Dp = p1 + p2 + … + pn`
- 直接乘算结果：`Dt = t1 + t2 + … + tn`（**相加**，非叠乘）
- 最终加算结果：`Fp = p1 + p2 + … + pn`
- 最终乘算结果：`Ft = t1 × t2 × … × tn`（叠乘；任意一项 < 0 时自动补正为「原值 + 1」）

最终（实际）属性：

```
Af = Ft × [(A + Dp) × (1 + Dt) + Fp]
```

其中若 `1 + Dt < 0`，`(1 + Dt)` 补正为 0；之后经数值范围限制上下限得到最终结果。

## 3. 基本公式

### 3.1 倍率

倍率是可能被技能等外部因素影响的变量，初始值 1.0。**倍率不是属性**，同种倍率间叠乘：`M = m1 × m2 × … × mn`。

- **攻击力倍率**：最基础的攻击力修正值（「攻击力提高至 X%」）。
- **伤害倍率**：只对其对应伤害类型生效（「受到的法术伤害 +X%」）。
- **治疗倍率**：修正治疗类效果（「治疗相当于攻击力 X%」）。

基本伤害：

```
基本伤害 = 攻击力 × 攻击力倍率 + 附加攻击力
```

治疗也属于一种伤害类型，适用此公式。

### 3.2 伤害公式

记 `A` 为基本伤害。

**物理伤害**：

```
DMG_p = max(0.05×A, A - [(1 - Ip) × max(0, D - Iv)])
```

- `Ip`：物理穿透（百分比）
- `D`：目标防御力最终结果
- `Iv`：物理穿透（固定值）

**法术伤害**：

```
DMG_a = max(0.05×A, 0.01×A × max(0, 100 - (1 - Ip) × max(0, D - Iv)))
```

- `Ip`：法术穿透（百分比）
- `D`：目标法抗最终结果
- `Iv`：法术穿透（固定值）

**元素伤害**：

```
DMG_e = max(0.05×A, 0.01×A × max(0, 100 - D))
```

- `D`：目标元素抗性最终结果（元素损伤把 `D` 换成损伤抵抗）

**真实伤害**：

```
DMG_pu = A
```

**治疗量**：

```
DMG_h = A
```

### 3.3 攻速公式

```
实际攻击间隔 T = T0 / (clamp(S, 10, 600) / 100)
```

- `T0`：理论攻击间隔（干员页面攻速显示对应的区间）
- `S`：攻击速度，默认 100
- `clamp(S, 10, 600)`：S 超出 10~600 时取最近端值（实际攻击速度属性下限为 20）

| 描述 | 区间 |
|---|---|
| 非常快 | < 0.8s |
| 快 | 0.8s ~ 1.0s |
| 中等 | 1.0s ~ 1.2s |
| 较慢 | 1.2s ~ 1.6s |
| 慢 | ≥ 1.6s |

每秒攻击次数 = 1 / 实际攻击间隔。

> PVZ 干员实现：`attack_cd = T0 × 100 / S`，其中 `S = 100 + 攻速加成总和`。例如「+3 攻速」即 `S = 103`。

### 3.5 移速

- 敌人每帧以寻路算法向目标点移动 `移动速度 × m ÷ 帧率` 格，`m` 为 `move_multiplier`，默认 0.5。
- 移动速度下限 0.1（`move_multiplier` 为 0.5 时实际每秒 0.05 格），无上限。
- 我方干员、装置、召唤物移动速度均为默认 1.0。

### 3.6 阻挡半径

- 地面阻挡半径 = 0.70709997（平方 = 0.49999037）
- 飞行阻挡半径 = `0.8944 × 阻挡半径倍率`（平方 = `0.79995137 × 倍率²`）
- 装置可覆写阻挡半径平方数；巨型装置固定为 0.49999037。

### 3.7 闪避公式

仅拥有多个闪避效果时，最终闪避成功率视为叠乘：

```
P = 100% - [1 - (1 - Pa)(1 - Pb) … (1 - Pn)]
```

### 3.8 维持技能状态

部分技能开启后单位不执行普攻，进入持续执行技能效果的恒定状态。

时间模式：

- **跟随攻速**：技能攻击间隔以攻击速度为准。
- **跟随动画**：以一次技能循环 Spine 动画周期为攻击间隔。
- 其余待确认。

区别于一般技能：免疫各类攻速减速/加速；眩晕、冻结等硬控会提前结束维持技能状态。

## 4. 基建

### 4.1 贸易站

- **心情消耗/时**：默认 1；进驻 2 人 -0.05，进驻 3 人 -0.1；每名中枢干员 -0.05。

```
实际每小时心情消耗 = 1 + 贸易站基础加成 + 后勤/中枢加成 + 对当前干员生效的后勤加成
```

- **获取订单效率**：每进驻 1 名干员 +1% 基础加成。

```
实际获取订单效率 = 1 + 基础加成 + 后勤技能加成
```

订单获取用时（龙门商法）：

| 建筑等级 | 订单所需 | 订单报酬 | 获取所需时间 |
|---|---|---|---|
| 1 | 赤金×2 | 龙门币 1000 | 2:24:00 |
| 2 | 赤金×3 | 龙门币 1500 | 3:30:00 |
| 3 | 赤金×4 | 龙门币 2000 | 4:36:00 |
| 3 | 源石碎片×2（开采协力） | 合成玉 20 | 2:00:00 |

赤金订单出现概率：

| 订单所需 | 贸易站1级 | 贸易站2级 | 贸易站3级 |
|---|---|---|---|
| 赤金×2 | 100% | 60% | 30% |
| 赤金×3 | 0% | 40% | 50% |
| 赤金×4 | 0% | 0% | 20% |

### 4.2 训练室

基本训练时间：

| 专精阶段 | 用时 |
|---|---|
| 0→1 | 08:00:00 |
| 1→2 | 16:00:00 |
| 2→3 | 24:00:00 |

协助位任意未涣散干员 +5% 训练速度：

```
实际训练时间 = 基本训练时间 / (1 + 0.05 + 协助干员后勤技能加成)
```

### 4.3 宿舍

```
每小时恢复心情 = 1.5 + 0.1 × 宿舍等级 + 0.0004 × 实际宿舍氛围 + 宿舍内干员技能加成
```
