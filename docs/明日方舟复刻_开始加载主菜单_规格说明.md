## 1. 工程架构（源码事实）

### 1.1 单例体系

| 单例 | 基类 | 职责 |
|---|---|---|
| `UIManager` | `Single<UIManager>` | 全局 Canvas/Camera、UI 加载/显示/隐藏 |
| `SoundManager` | `MonoSingle<SoundManager>` | 音效/音乐/语音 3 条 AudioSource、intro→loop BGM |
| `PlayerManager` | `Single<PlayerManager>` | 账号列表（ScriptableObject）、Login/Register/Exit |
| `Delay` | `MonoSingle<Delay>` | 延迟动作（Update 倒计时） |
| `EventSystem` | `Single<EventSystem>` | 反射事件总线 |
| `LuaEnvManager` | `Single<LuaEnvManager>` | XLua 虚拟机、加载 `LuaScripts/**` |
| `ABManager` | `Single<ABManager>` | AssetBundle 加载（依赖清单） |
| `CharManager`/`ItemManager`/`ShopManager`/`DungeonManager` | `Single<*>` | 元数据 + Sprite 缓存 |
| `GameManager` | `MonoSingle<GameManager>` | 战斗预制体/音频 |

### 1.2 启动序列（`GameStart.cs`）

```
Awake():
  GameManager.Inst()      # 预加载战斗资源
  LuaEnvManager.Inst()    # XLua 虚拟机 + require('Global.Global') 注入全局
  UIManager.Inst().Show("LoginUI")   # 首屏
  Destroy(gameObject)
```

### 1.3 UIManager 生命周期（`UI/UIManager.cs`）

- 初始化：实例化 `Prefab/UI/Camera`（内含 Canvas）→ `DontDestroyOnLoad`。
- Canvas 尺寸：读取 `CanvasScaler.referenceResolution`，**按高度适配**：
  `canvasSize.x = canvasSize.y * Screen.width / Screen.height`。
- `Show(type)`：字典缓存 → 无则 `Instantiate(Prefab/UI/<type>)` 挂 Canvas → `SetAsLastSibling()` → `Show()` → `UpdateView()` → `state = Show`。
- `Hide(type, destroy)`：`state == Show` 时 `Hide(destroy)`；`destroy` 为真时 `UnLoad` 销毁并移除缓存。
- `UIBase`（`UI/UIBase.cs`）：抽象基类，`Init()`（首次）/ `UpdateView()`（数据刷新）/ `Show()` / `Hide(bool destroy)`；`canvasGroup` 统一控制透明度。

### 1.4 RuaUI（Lua 驱动 UI，`UI/RuaUI.cs`）

- 场景根挂 `RuaUI`，`Init()` 时 `LuaEnv.DoString(LoadLuaText("UI."+Name))`。
- Lua 文件加载顺序：`LuaScripts/Global/Global.lua.txt`（全局注入）→ `LuaScripts/UI/<Name>.lua.txt`。
- 注入：`self`（UIBase）、`Injection[]`（Prefab 上声明的字段引用，如 `cardPrefab`）。
- Lua 回调约定：`init()` / `update()`（每帧）/ `updateView()` / `show()` / `hide(destroy)` / `BaseShow()` / `BaseHide()`。

### 1.5 事件总线（`Event/EventSystem.cs`）

- 监听者实现 `Listener` 接口，方法标 `[EventHandler]`、单参、参数类型继承 `Event` 且非抽象。
- `AddListener` / `RemoveListener` 用反射扫描；`Call(Event)` 分发。示例见 `GameUI.OnCreateEvent(CreateEntityEvent)`。

### 1.6 状态机（`Game/State.cs`）

- `StateManager`：`AddStatus(name, State)`；`State.OnEnter/OnStay/OnExit/AddCondition`；`Tick()` 内先跑总条件再跑子条件跳转。
- 使用范例：`SelectDungeonUI.Ground` 的地面切换状态机、`GameUI` 的战斗阶段（`dungeon.sa.Name = "Run"`）。

## 4. 开始界面（LoginUI）规格

### 4.1 节点层级（`transform.Find` 路径 = 源码确定）

```
LoginUI (CanvasGroup)  ← UIManager 挂到 Canvas，SetAsLastSibling
├── sphereCamera (Camera)              # 只渲染 sphere 的相机；背景色红↔黑缓动
├── sphere (RectTransform)             # 星球；DOAnchorPosY / DOScale
├── backGround (CanvasGroup)           # 登录/注册时压暗底（alpha 0↔1）
├── homePanel (CanvasGroup)            # 首页：标题 + 登录/注册 两按钮
├── loginPanel (CanvasGroup)           # 登录：userName / password InputField + enter / back
├── registerPanel (CanvasGroup)        # 注册：userName / password / rePassword + toggle + enter / back
├── lowerRightPanel (CanvasGroup)      # 右下角信息（版本号等）
└── loadingPanel (CanvasGroup)         # 加载：loading_bar1 / loading_bar2 / bar1Text / bar2Text
```

### 4.2 布局（1920×1080 空间）

| 节点 | 建议尺寸/位置【推断】 | 依据 |
|---|---|---|
| sphere | 1200×1200，锚点中心，初始 `anchoredPosition=(0,263)`，scale 1 | 源码只给 y 位移：263(首页)→140(注册)→0(登录)→-540(加载)；scale 1→0.8 |
| sphereCamera | 正交相机，只渲染 sphere 层，clear color 红 `(0.74,0.36,0.36)` | 源码相机颜色红/黑 |
| backGround | 全屏 | DOFade 0/1 |
| homePanel | 全屏；中央标题区 y≈400~560；`登录` 按钮 (830,470)、`注册` 按钮 (1090,470) | 面板全屏，按钮居中偏下【推断】 |
| loginPanel | 中央面板 480×320，y≈470；两输入框各 400×56 | 弹层居中【推断】 |
| registerPanel | 中央面板 480×420 | 比登录多一输入框+协议勾选【推断】 |
| lowerRightPanel | 右下角 (1650,60) | 版本信息【推断】 |

### 4.3 动画规格（源码精确参数，DOTween）

| 触发 | 动画序列 | 时长 | 缓动 |
|---|---|---|---|
| home→login | `homePanel.DOFade(0)` → OnComplete：homePanel 失活；loginPanel 激活 + `DOFade(1)`；`backGround.DOFade(1)`；`sphere.DOAnchorPosY(0)`；`sphereCamera.DOColor(black)` | 0.5s / 0.5s / 0.5s / 1s / 1s | 默认（OutQuad） |
| login→back | `loginPanel.DOFade(0)` → OnComplete：清空密码；loginPanel 失活；homePanel 激活 + `DOFade(1)`；`backGround.DOFade(0).SetDelay(0.5)`；`sphere.DOAnchorPosY(263).SetEase(Linear)`；`sphereCamera.DOColor(red)` | 0.5s / 0.5s / 0.5+0.5s / 1s / 1s | Linear |
| home→register | 同 home→login，`sphere.DOAnchorPosY(140)` | 同 | 默认 |
| register→back | 同 login→back（清空两密码框） | 同 | Linear |
| login 成功 | `lowerRightPanel.DOFade(0)`；`loginPanel.DOFade(0)` → OnComplete：lowerRight 失活；loadingPanel alpha=0 激活 + `DOFade(1)`；`sphere.DOScale(0.8).SetEase(Linear)`；`sphere.DOAnchorPosY(-540).SetEase(Linear)` → OnComplete 启动进度条 | 0.5s / 0.5s / 0.5s / 1s / 1s | Linear |
| Show() | `canvasGroup.DOFade(1)`；`PlayMusic(intro,false,→loop)` | 0.5s | 默认 |
| Hide() | `canvasGroup.DOFade(0)` → base.Hide | 2s | 默认 |

颜色常量：`black = Color(0,0,0,0)`（相机转黑）、`red = Color(0.74,0.36,0.36,0)`（相机转红）。

### 4.4 交互与校验逻辑（源码确定）

- `home_login`：切登录面板（§4.3）。`login_back`：返回首页并清空密码。
- `login_enter`：
  1. `PlayerManager.Inst().Login(name, password)`（遍历 `Data/User` 下账号匹配 name+password，成功 `data.ItemSort()`）。
  2. 失败 → `CommonDialogUI.Message(BLACK, "用户名或密码错误 请重新登录")`。
  3. 成功 → 进入加载界面（§5）。
- `register_enter` 校验链（按序失败弹出 BLACK 提示并 return）：
  1. `userName.Length < 3` → "用户名不得小于三位"。
  2. `password != rePassword` → "密码不一致"。
  3. `password.Length < 6 || > 18` → "密码为6-18位的数字，字母，字符(可包含!#$%&*,.:;^`~)"。
  4. `!toggle.isOn` → "需同意注册协议和隐私协议"。
  5. `Register` 抛异常 → 显示异常信息。
  6. 成功 → `CommonDialogUI.Message(WHITE, "注册成功").AddBackListener(→ register 面板淡出回首页)`。
- `sphere` / `backGround` / 面板激活切换全部走 CanvasGroup 透明度动画，**禁用即失活**。

## 5. 加载界面（LoginUI.loadingPanel）规格

### 5.1 进度算法（源码精确）

- 初始 `value = 0.02`（条上文字显示 `value*200 = 4%`）。
- 主进度：`DOTween.To(()=>value, v=>value=v, 0.5f, 3f).SetEase(Ease.InQuint)`。
  - 每帧：`loading_bar1.anchorMax.x = value`（左条向右伸展）；`loading_bar2.anchorMin.x = 1 - value`（右条向左伸展）；两 Text = `$"{value*200:0.##}%"`。
- 完成：`value → 0`（0.5s）→ `Delay.add(() => UIManager.Show("HomeUI"), 2)`；`UIManager.Hide("LoginUI", true)`。
- 加载真实工作量在源码中**未实现**（纯演示动画）；复刻时可将 HomeUI 资源的异步加载挂到该进度上（映射见 §9-B）。

### 5.2 关键时间轴

| 时刻 | 事件 |
|---|---|
| 0.0s | sphere scale→0.8（1s）、y→-540（1s） |
| 0.5s | loadingPanel 淡入完成 |
| 1.0s | sphere 动画完成 → 进度条启动（InQuint，3s） |
| 4.0s | 进度 0.02→0.5 完成 → value→0（0.5s） |
| 4.5s | 归零完成 |
| 6.5s | `Delay 2s` 到点 → Show HomeUI + Hide LoginUI(destroy) |

### 6.3 视差动画算法（源码精确，逐帧 update）

```
if 鼠标在屏幕内:
    target = (mousePos - CanvasSize/2) / CanvasSize/2
current = Vector2.Lerp(current, target, 1.5 * Time.deltaTime)   # 平滑跟随

move1.localPosition.x = current.x * 50
move1.localPosition.y = current.y * -30

move2.eulerAngles.y = current.x * -3
move2.eulerAngles.x = current.y * 4
move2.localPosition.y  = -current.y * 30
```

### 6.4 生命周期（源码精确）

- `show()`：`BaseShow()`；`PlayMusic(m_sys_void_intro, false, cb→PlayMusic(m_sys_void_loop, true))`；`canvasGroup.alpha=0 → DOFade(1, 0.5)`。
- `hide(destroy)`：`DOFade(0, 0.5).OnComplete → BaseHide(destroy)`。
- `updateView()`：在 `Show()` 后由 UIManager 调用；切换用户/登出后需重刷。

### 6.5 登出流程（SettingUI 内，源码精确）

```
设置 → "返回登录" 按钮：
  CommonDialogUI.Message(WHITE, "即将返回登陆界面，是否继续？", 确认回调)
  → PlayerManager.Exit()
  → UIManager.Hide("HomeUI", true) / Hide("SettingUI", true) / Hide("HouseUI", true) / Hide("CharUI", true)
  → DOTween.To(v: 0→3, 2s).OnComplete → UIManager.Show("LoginUI")   # 2s 后回到登录
```

## 8. 状态管理与事件设计

1. **UI 状态机**：`UIBase.state`（UIState.Show/Hide）防止重复 Show/Hide；`UIManager` 字典管理单例 UI（复用不销毁，除非 destroy）。
2. **面板状态机**：`StateManager`（`Game/State.cs`）——`SelectDungeonUI.Ground` 用状态机切换地面明暗；可用它实现"登录阶段/加载阶段/主菜单阶段"的强约束状态切换。
3. **事件总线**：`EventSystem`——战斗实体创建/移除等跨模块通知走 `[EventHandler]`；登录成功/登出这类跨界面事件也建议走事件总线（源工程用 UIManager.Show/Hide 直调）。

// UIManager.Show 核心（UI/UIManager.cs）
public UIBase Show(string type) {
    if (!uiDictionary.TryGetValue(type, out UIBase ui)) {
        GameObject obj = Object.Instantiate(Asset.Load<GameObject>(GameSettings.UI_PREFAB_PATH, type), canvas.transform);
        ui = obj.GetComponent<UIBase>(); ui.Name = type; ui.Init();
        uiDictionary.Add(type, ui);
    }
    ui.transform.SetAsLastSibling();
    ui.Show(); ui.UpdateView();
    if (ui.state != UIState.Hide) return ui;
    ui.state = UIState.Show;
    return ui;
}

### 9-B. Godot 4 移植方案（本仓库 ArkPvZ，推荐实施路径）

**框架**：Godot 4.7（GDScript，GL Compatibility）——复用本仓库已建成的 `00StartScreen`/`00LoadingScreen`/`01MainMenu` 启动管线，按本规格补齐"方舟感"细节。

**节点结构映射**：

| Unity | Godot 4 |
|---|---|
| Canvas + CanvasScaler | 根 Control（stretch mode `canvas_items`，视口 1066×600） |
| CanvasGroup + DOFade | `modulate:a` + `create_tween().tween_property(...)` |
| Image.fillAmount | `TextureProgressBar.value/9` 或 ColorRect 宽度动画 |
| sphereCamera/星球 | 静态 `GradientTexture2D`(FILL_RADIAL) TextureRect + 相机用全屏 ColorRect 覆盖调色 |
| RectTransform.anchorMax/min | Control 锚点 + `size.x` 驱动 |
| Input.mousePosition 归一化 | `get_viewport().get_mouse_position() - get_viewport_rect().size/2` |
| DOTween.Ease.InQuint | `Tween.EASE_OUT` + `TRANS_QUINT` |
| DOTween.Ease.Linear | `TRANS_LINEAR` |

**缓动映射表**：

| DOTween | Godot Tween | 用途 |
|---|---|---|
| 默认（OutQuad） | `TRANS_QUAD, EASE_OUT` | 面板淡入淡出 |
| `Ease.Linear` | `TRANS_LINEAR` | 星球位移/缩放 |
| `Ease.InQuint` | `TRANS_QUINT, EASE_IN` | 加载进度条加速 |
| `DOFade`（透明度） | `tween_property(..., "modulate:a", ...)` | 所有透明度 |

**关键 GDScript 示例**：

## HomeUI 鼠标视差（等价 HomeUI.lua update()）
func _process(_delta: float) -> void:
	var size: Vector2 = get_viewport_rect().size
	var mouse := get_viewport().get_mouse_position()
	if mouse.x > 0 and mouse.x < size.x and mouse.y > 0 and mouse.y < size.y:
		_target = (mouse - size * 0.5) / (size * 0.5)
	_current = _current.lerp(_target, 1.5 * _delta)          # 1.5*dt 平滑
	move1.position = Vector2(_current.x * 50.0, _current.y * -30.0)
	move2.position = Vector2(move2.position.x, -_current.y * 30.0)
	move2.rotation_degrees = Vector2(_current.y * 4.0, _current.x * -3.0)
