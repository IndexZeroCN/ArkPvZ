# 危机合约 · 通关攻略

> 冒险模式第 6 关「危机合约」：**自选卡组**（干员 + 植物均可），通过自选「词条」提升难度，
> 防守 30 波僵尸（出怪 ×2、蹦极来袭）。词条可**削减卡槽、逐出干员、放大僵尸**——词条拉满即是炼狱。
> 本攻略基于关卡初始配置与四名干员的满级数值分析撰写，含**满词条通关思路**。

## 2. 四名干员深度分析

### 克洛丝（速射手 · 费用 8 · 常驻单体输出）
- **特性**：攻速最快（1.0s），单体 DPS ≈ 396；天赋「要害瞄准」20% 概率当次攻击 **150%**。
- **技能·二连射**（攻击回复，5 点就绪）：下次攻击连射 2 发（≈792 瞬间爆发）。
- **用法**：**最便宜的常驻输出**，开局第一优先部署；打普通/路障/报纸绰绰有余，铁桶（1370）约 3.5 秒一只；**负责打气球防空与补刀**。
- **短板**：单体无溅射，打群怪和肉盾效率低——肉盾交给维什戴尔与羽毛笔。

### 维什戴尔（投掷手 · 费用 23 · 群伤主力）
- **特性**：5×5 菱形溅射，攻击 809、攻速 2.1s；**范围覆盖多路**，是唯一的跨行群伤。
- **技能**（手动触发）：
  - **S1 定点清算**：下次攻击附加 2 次余震并晕眩 1.5s——**打断/控制**，压制巨人或大波前排。
  - **S2 饱和复仇**：攻击 +35%、攻速缩短、攻击 3 名敌人；过载 4 连发（80%）——**常态强化群伤**，主带推荐。
  - **S3 爆裂黎明**：攻击 +180%，召唤 2 个魂灵之影，6 发弹药打 220%——**全关最强爆发**，留给巨人集群/终盘大波。
- **用法**：**放全图中心偏后**让菱形罩住最多线路；23 费是最贵干员，**中后期部署**。
- **短板**：攻速慢，**单挑肉盾不如克洛丝**；被蹦极抓走代价极高。

### 桃金娘（先锋·执旗手 · 费用 8 · 经济核心）
- **特性**：费用最低，射程只有自身+前方 1 格；**技能期间停止攻击且阻挡数变 0**。
- **技能**：
  - **S1 支援号令·β**：停止攻击 8 秒，回复 **14 点 DP**——前期经济命脉，开局必开。
  - **S2 治愈之翼**：16 秒回 **16 点 DP** 并每秒治疗一名友方 50% 攻击力（≈260）——中期奶妈。
- **用法**：
  - **开局第一下必须是桃金娘**：8 费下 → 立刻开 S1 → 8+14=22 点，够铺克洛丝 + 攒羽毛笔。
  - 放**边路靠后**；技能结束及时撤退重下循环赚费；有 S2 后当移动奶妈。
- **短板**：技能期间阻挡 0，**她身后不能就是家门口**。

### 羽毛笔（近卫·收割者 · 费用 20 · 近战盾线）
- **特性**：四人中最肉（2250）且**阻挡 2**，近战 650 DPS——**物理防线核心**。
- **技能**：
  - **S1 高速切割**（攻击回复）：下次攻击 **165% × 2 连击**（≈2145）——单体斩杀，打铁桶/铁门/橄榄球。
  - **S2 收割**（手动）：攻击 +70%、攻速缩短，对低于 50% 血的敌人再 +50%——**攻坚巨人**。
- **用法**：放僵尸**最密集的一行**阻挡 2 条线；**放第二列可拦截挖地僵尸出土**。
- **短板**：近战，挡不住气球/跳跳/撑杆；费用较高。

## 3. 卡组选择（6 格自选）与植物搭配

干员页永远提供 4 名干员；植物页提供全部已解锁植物。**混编思路**：

### 干员为骨、植物为肉（推荐）
| 卡位 | 选择 | 作用 |
|---|---|---|
| 1 | 桃金娘 | DP 经济发动机（必带） |
| 2 | 克洛丝 | 廉价单体 + 防空补刀（必带） |
| 3 | 羽毛笔 | 近战盾线、阻挡 2（必带） |
| 4 | 维什戴尔 | 群伤爆发、打巨人（必带） |
| 5-6 | 植物自由位 | 推荐：坚果/高坚果（盾）、冰西瓜/寒冰射手（减速控场）、玉米加农炮（爆发）、魅惑菇（偷僵尸）、地刺王（克车类） |

### 植物向打法（如果不想用某个干员）
- **向日葵/阳光菇**：补阳光经济，支撑更重的植物体系。
- **冰西瓜/寒冰射手**：全场减速，配合克洛丝单体点杀。
- **高坚果 + 土豆雷**：防线外再叠一层物理墙。
- **玉米加农炮**：手动爆发清大波，替代维什戴尔的功能位。

> 注意：**逐出令**词条会直接从干员页移除对应干员，所以至少带 4 格干员是为了应对词条组合——被逐出后要有替代（植物或其它干员）。

## 5. 开局与费用节奏（0 词条基准）

1. **第 0 秒：下桃金娘**（8 DP 用光）→ 立刻开 **S1**，8 秒回 14 点。
2. **第 8 秒（DP≈14）：下克洛丝**（-8）守第一条压力线；有余裕就种 1~2 株向日葵/阳光菇垫经济。
3. **攒到 20：下羽毛笔**（-20）放**最前线/僵尸最密的一行**，阻挡 2 建立盾线。
4. **桃金娘技能结束** → 撤退重下循环赚费；S2 解锁后留场当奶。
5. **DP 到 23：下维什戴尔**（-23）放中心菱形覆盖多路——安全期开始。
6. **植物补充**：在安全行铺减速/输出植物，把防线压到前场。

> 费用规律：DP 上限 99、回复 0.67/s。四名干员全部上场共需 8+8+20+23=59 点，
> 桃金娘 S1 循环下约 60 秒可全队就位。植物吃阳光、干员吃 DP，**两套经济并行不抢**。

**站位铁律**：
- 桃金娘**永远不要当最后一道防线**（技能期间阻挡 0）。
- 羽毛笔放**第二列**可拦截挖地僵尸出土。
- 维什戴尔菱形范围**对准中路偏前**，让溅射同时照顾两路。
- 克洛丝留在后方纵深，负责补刀漏网与打气球。

## 7. 高难词条组合实战思路

- **磐石（血×10）**：所有僵尸都是血牛，克洛丝沦为补刀，**DPS 主力完全压在维什戴尔技能上**；建议 S3 常驻、S2 过渡。桃金娘 S2 治疗在持久战里价值极高。
- **疾驰（速×2）**：撑杆/跳跳/橄榄球极快冲到盾线，**开局要把克洛丝放得靠前**，别等僵尸堆到脸上。
- **断援（无小推车）**：**任何一行都不能破防**；单线失守就重开，不要恋战。
- **补给枯竭**：桃金娘 S1 循环的 14 点费是**唯一经济来源**，撤退/再部署节奏不能断；维什戴尔 23 费会非常晚才能下。
- **逐出令·执旗（禁桃金娘）**：DP 回复 0.67/s 硬攒，开局只能先铺植物过渡（向日葵/阳光菇 + 坚果），等 20+ 费再考虑羽毛笔/维什戴尔——**节奏整体后移**，前 5 波是关键。
- **逐出令·投掷（禁维什戴尔）**：没有溅射，大波全靠克洛丝/羽毛笔 + 植物群伤（冰西瓜/玉米加农炮）顶。

## 8. 满词条攻略（全 16 词条拉满）

**词条全选**：磐石 + 疾驰 + 凶残 + 潮涌 + 持久战 + 迷雾封锁 + 补给枯竭 + 开局受限 + 断援 + 精简编队 + 极限编队 + 逐出令×4。
（同组互斥：磐石/铁壁取磐石，逐出令四选一。）

**满词条最终形态**：卡槽 3（只能带 3 张卡）、初始 DP 4、DP 回复 3s/点、无小推车、40 波 ×3 倍出怪、僵尸血 ×10、速 ×2、攻 ×2、迷雾、且被逐出一名干员。

### 8.1 满词条卡组选择（只能 3 格）
逐出令选谁，直接决定最后 3 格：
- **逐出·投掷（禁维什戴尔）**：带 **桃金娘 + 克洛丝 + 羽毛笔**。无群伤 → 靠植物（冰西瓜/玉米加农炮）补，但只有 3 格植物/干员混编空间，建议 **桃金娘 + 羽毛笔 + 玉米加农炮** 或 **桃金娘 + 克洛丝 + 玉米加农炮**（植物向）。
- **逐出·执旗（禁桃金娘）**：带 **克洛丝 + 羽毛笔 + 维什戴尔**。无 DP 经济 → 植物经济撑场，但 3 格只剩 1 个植物位：**克洛丝 + 羽毛笔 + 玉米加农炮** 最稳（加农炮手动清波），维什戴尔太贵节奏断。
- **逐出·速射 / 收割**：保留桃金娘经济，带 **桃金娘 + 维什戴尔 + 羽毛笔**（若逐出克洛丝）或 **桃金娘 + 克洛丝 + 维什戴尔**（若逐出羽毛笔）。

> 满词条下**玉米加农炮是性价比之王**：无视血 ×10 的肉盾、手动爆发清大波、被逐出令不波及（不是干员）。

### 8.2 满词条对局节奏
1. **前 20 秒（最危险）**：初始 DP 4、回复 3s/点——**什么都下不了**。开局就来的僵尸只能靠……
   - 满词条**没有小推车**，一旦漏僵尸=直接失败。
   - **关键**：第 1 波大波前至少要站住 1 个阻挡位。DP 4 → 攒 8 费下桃金娘（约 12 秒）→ 开 S1 回 14 → 下克洛丝/羽毛笔。
   - 若逐出桃金娘：只能攒 20 费下羽毛笔（约 48 秒），**前 40 秒全靠天降阳光 + 100 初始阳光种向日葵/坚果死撑**。
2. **中期（5~20 波）**：桃金娘 S1/S2 循环是唯一 DP 来源；玉米加农炮瞄准巨人/投石车/大波中心；羽毛笔守一条线，克洛丝/维什戴尔补输出。
3. **后期（21~40 波）**：潮涌 ×3 + 磐石 ×10 意味着**每波都是大波**。维什戴尔 S3 + 玉米加农炮双爆发轮换，桃金娘 S2 保盾线。迷雾下用"炮塔编队"——把输出集中在已知的刷怪行。
4. **失败重开判定**：任何一行破防（无推车）立即重开；**满词条重开几十次是常态**，目标是有一次完美节奏。

### 8.3 满词条专属要点
- **冰西瓜 > 寒冰射手**：潮涌下减速面越大越好。
- **地刺王**：无视血 ×10 的车类（推土机无车，但有投石车/梯子），地刺王对投石车/梯子有效。
- **墓碑/蹦极**：大波蹦极偷干员是最大减员点——满词条下被偷 1 个几乎必败，**大波前 5 秒把最贵干员换位**。
- **操作密度**：满词条约每 3 秒需要一个操作（技能/加农炮/换位），**不建议开加速**。
